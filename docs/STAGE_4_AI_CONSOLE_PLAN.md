# 阶段 4：AI 控制台详细规划

最后更新：2026-06-01

## 阶段目标

在现有学生管理系统基础上，增加 AI 辅助功能层。
AI 读取系统数据，生成内容和建议，老师审核后使用。
不自动修改收费、考勤、删除类数据。

---

## 第一批 AI 功能（优先级排序）

### F1：生成学生阶段反馈

**触发入口**：学员详情页 → 点"AI 生成反馈"按钮

**AI 读取的数据**：
- 该学员的成绩记录（最近 5-10 次）
- 该学员的考勤记录（最近 1 个月）
- 该学员的缴费记录（已缴课时、剩余课时）

**输出**：一段文字反馈稿

```
格式：
[学员姓名] 近期学习情况（2026年X月）

学习表现：...
主要进步：...
薄弱知识点：...
建议：...

生成时间：2026-06-01
```

**用户操作**：点"复制" → 粘贴到微信发给家长

**技术实现**：
1. 前端把学员 ID 发给后端
2. 后端调 AI API，把数据组装成 prompt
3. AI 返回文字结果
4. 前端展示，支持复制

---

### F2：生成续费沟通话术

**触发入口**：两个入口
- 首页"欠费提醒" → 点学员 → "生成话术"
- 学员详情页 → 点"AI 生成话术"

**AI 读取的数据**：
- 学员已缴课时、已消课时、剩余课时
- 学员历史续费记录
- 班级信息（当前在读班级、课程进度）

**输出**：微信话术，支持不同语气

```
【催续费话术 - 温和版】
王五妈妈您好，王五在我们班学习快两个月了，目前还剩X课时。
考虑到孩子的学习连续性，建议近期安排续费。
您看这周方便沟通一下吗？

【催续费话术 - 直接版】
王五妈妈，王五剩余课时不足，建议本周内确定续费安排。
```

**用户操作**：选一个版本 → 复制 → 发微信

---

### F3：生成本周经营报告

**触发入口**：首页顶部 → 点"AI 生成周报"

**AI 读取的数据**：
- 本周新增学员数量
- 本周出勤人次（各班级考勤汇总）
- 本周收费金额（已缴记录）
- 本周欠费金额
- 本周沟通记录数量
- 续费提醒列表

**输出**：一段周报文字

```
【白老师本周经营周报】
时间：2026年5月26日 - 6月1日

学员动态：
- 新增在读学员 X 名
- 本周出勤共 Y 人次
- 续费提醒：X 名学员课时不足

财务摘要：
- 本周已缴 ¥XXX
- 本周欠费 ¥XXX

下周建议：
- 重点跟进 X 名待续费学员
- 班级满班率 XX%
```

**用户操作**：复制 → 粘贴到自己保存经营数据的地方

---

### F4：生成朋友圈招生文案

**触发入口**：营销模块（预留入口）→ 点"AI 生成招生文案"

**AI 读取的数据**：
- 当前开设的班级（名称、年级、时间、收费）
- 课程特色描述（暂无，可留空让 AI 通用描述）

**输出**：3-5 条不同风格的朋友圈文案

```
【招生文案 A - 家长视角】
孩子数学跟不上？
白老师六年级数学班开课了，小班教学，针对性辅导。
目前还有少量名额，感兴趣的家长可以私信我。

【招生文案 B - 成绩视角】
上次期末考，我们班平均提分 15 分。
六年级数学培优班招生中，想提升数学成绩的家长欢迎咨询。

【招生文案 C - 简短直接】
六年级数学提升班招生！
上课时间：周六 14:00-16:00
报名请私信，名额有限。
```

**用户操作**：选一条 → 复制 → 发朋友圈

---

### F5：生成试听前诊断问题

**触发入口**：意向学员 → 点"试课" → "生成诊断问题"

**AI 读取的数据**：
- 意向学员的年级
- 意向学员目前成绩（如果有填）
- 当前班级课程内容（可选）

**输出**：3-5 道诊断题目

```
【六年级数学试听诊断题】

1. 计算：3/5 + 2/7 = ?
2. 解方程：2x + 5 = 15
3. 应用题：...（考察理解能力）

说明：这套题约 15 分钟做完，试课后可评估学生当前水平。
```

**用户操作**：复制 → 给试课学生做

---

### F6：生成试听后转化话术

**触发入口**：意向学员 → 试课结束 → "AI 生成转化话术"

**AI 读取的数据**：
- 意向学员年级、微信
- 试课表现（如果有记录）
- 当前班级课程安排和收费

**输出**：家长微信话术

```
【试听转化话术】
王五妈妈，孩子今天试听表现很不错，数学基础挺好的。
我们六年级数学周六班正好还有名额，
您看要不要让孩子正式加入？第一个月收费 XXX 元。
```

## 功能优先级和工作量

| 功能 | 优先级 | 技术难度 | 数据依赖 |
|------|--------|---------|---------|
| F1 生成学生阶段反馈 | ★★★★★ | 低 | 成绩 + 考勤 + 缴费 |
| F2 生成续费沟通话术 | ★★★★★ | 低 | 缴费 + 考勤 |
| F3 生成本周经营报告 | ★★★★☆ | 中 | 全局汇总计算 |
| F4 生成朋友圈招生文案 | ★★★★☆ | 低 | 班级信息 |
| F5 生成试听前诊断问题 | ★★★☆☆ | 低 | 意向学员数据 |
| F6 生成试听后转化话术 | ★★★☆☆ | 低 | 意向学员 + 班级 |

**建议顺序**：F1 → F2 → F3 → F4 → F5 → F6

## 统一技术方案

### AI 接口选择

**推荐：Deepseek API**（性价比最高）

- 价格便宜（比 Claude/OpenAI 便宜很多）
- 中文处理能力强
- 效果够用

**备选：Claude API**（效果最好）

- 贵一点，但输出质量更高
- 如果 Deepseek 效果不够用再换

### 前端交互设计

**每个 AI 功能都是同一个模式：**

```
点击按钮 → 显示"AI 生成中..." → 显示结果 → 复制/关闭
```

结果展示统一用现有的 modal 弹窗，不新增特殊 UI。

### 数据安全

- AI 读取的是系统已有数据，不写入新数据
- 所有 AI 输出必须经过老师确认再使用
- 不自动发送任何内容，不自动修改业务数据

### 后续扩展预留

- Agent 日志记录（每次 AI 调用写入 `agent_logs` 表）
- 批量生成（多个学员一起生成）
- 模板自定义（话术风格自己调整）

## 与现有系统对接方式

### 数据流

```
用户点击按钮
    ↓
前端调用 /api/ai/generate（POST）
    ↓
后端组装 prompt（读系统数据 + 用户指令）
    ↓
后端调用 AI API（Deepseek/Claude）
    ↓
AI 返回结果
    ↓
前端展示 modal
    ↓
用户复制使用
```

### API 设计

```
POST /api/ai/generate
Body: {
  "task": "student-feedback",
  "studentId": "s123",
  "options": {
    "tone": "normal"  // 预留：温和/直接
  }
}

Response: {
  "success": true,
  "result": "王五近期学习情况...\n主要进步...\n薄弱点..."
}
```

### 错误处理

- AI 接口超时：显示"生成失败，请重试"
- AI 返回内容异常：显示"生成结果异常，已记录"
- 网络问题：显示"网络异常，请检查连接"

## 后续 Agent 扩展（阶段5）

阶段 4 的第一批功能以"点一下生成内容"为主。
阶段 5 扩展为真正的 Agent：

- **教务 Agent**：自动监控学员课时，主动提醒
- **教研 Agent**：根据错题数据自动生成练习题
- **营销 Agent**：自动生成多平台文案、自动排期发布
- **发展顾问**：分析经营数据，给出建议

阶段 5 的前提：阶段 4 的数据积累和交互验证完成。

---

## 依赖关系

1. 阶段 3C 必须完成（AI 控制台依赖稳定的系统数据）
2. 阶段 4 第一批上线后，收集使用反馈
3. 根据反馈决定是否接入飞书/微信通知（阶段 4 后期或阶段 5）

## 备注

- AI 功能不改变现有系统 UI 结构
- 每个 AI 功能可以独立上线，不需要等全部完成
- 先做 F1/F2，两个功能共享数据源，可以一起开发
