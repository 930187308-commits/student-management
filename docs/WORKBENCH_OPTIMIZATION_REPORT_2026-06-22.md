完成当前主工作台的第一优先和第二优先优化：

## 已完成优化

### 1. 学员详情页

- 顶部保留三个高价值摘要：
  - 课时与收费
  - 最近成绩
  - 最近沟通
- 基础信息和入班记录改为更紧凑的卡片。
- 当前就读学校只显示当前阶段，可点开切换查看小学/初中/高中记录。
- 新增“最近时间线”，按时间混排收费、成绩、沟通、考勤和操作记录。
- 沟通记录默认折叠，标题和成绩记录标题左对齐。
- 成绩记录保留展开显示，便于后续接成绩趋势图。

### 2. 首页工作台

- 今日工作台第一入口改为“经营复盘”。
- 保留待续费/欠费、意向跟进、AI 对话入口。
- 快捷按钮改为紧凑网格，避免竖向过长。
- 待办为空时显示可一键加入的推荐事项：
  - 检查待续费和欠费学生
  - 补录本周考勤
  - 跟进意向学员

### 3. AI 系统问答

- 固定回归测试集已覆盖：
  - 可查询能力说明
  - 年级在读人数
  - 家长会建议不误触发学员名单
  - 结合系统数据的家长会建议
  - 100 分成绩查询
  - 不及格成绩查询
  - 学员学校
  - 学员课时余额
  - 学员成绩
  - 学员沟通
  - 班级成员
  - 班级课次进度
  - 上个月/本月课消
  - 学员上月出勤
  - 收费汇总
  - 经营复盘
  - 欠费与课时风险
  - 意向学员
  - 不可查询边界
  - 连续追问按班级分组
- 修复了“本月课消情况怎么样？”误触发经营复盘的问题。
- 新增“上个月课消”“本周经营复盘”“本周先处理谁”等高频问题回归。
- 修复经营复盘问题含“课消”时被误判为单项课消查询的问题。
- 当前回归测试结果：`27 / 27` 通过。

### 3.5 操作日志

- 新增 `operationLogs` 同步集合，不新增 SQLite 业务表。
- 核心模块通过统一保存/删除 API 自动记录新增、更新、删除：
  - 学员
  - 班级
  - 收费
  - 考勤
  - 成绩
  - 沟通
  - 意向学员
- 顶部新增“操作日志”按钮，可查看最近 100 条操作记录。
- 当前日志用于追溯；撤回仍使用顶部“撤回上一步”。

### 4. 资料库

- 资料库当前定位保持为：AI 可引用资料中心。
- 题库已拆到独立子工作台，不在资料库页面承载细节。
- 资料库页面重点保留：
  - 资料统计
  - 粘贴原文 / 网页地址 / 本地文件 / 文件夹或 Obsidian 导入
  - 资料列表
  - 右侧导入说明和默认 Obsidian 路径
- AI 实际可读的是资料库中保存的摘要、原文和引用片段；只保存路径不能让 AI 理解正文。

## 数据结构判断

本轮不需要修改底层数据结构：

- 未改 SQLite 表结构。
- 未新增迁移脚本；`server/db.js` 仅补充 `operationLogs` 默认集合与通用单条集合保存支持。
- 未新增业务表或字段。
- `operationLogs` 使用现有 app_state 同步集合保存，不需要迁移。
- AI 复盘和学员 AI 话术均为只读生成，不写入学员、收费、考勤、成绩、沟通等业务表。

当前数据体检仍有提示项：

- 课时余额为负明细：`14`
- 超过容量班级：`1`
- 停课/非在读学员仍有关联收费记录：`2`

这些属于业务提示，不是本轮必须自动清理的数据；安全清理项（孤立考勤、孤立收费、不存在学员 ID 的考勤记录）当前为 `0`。
