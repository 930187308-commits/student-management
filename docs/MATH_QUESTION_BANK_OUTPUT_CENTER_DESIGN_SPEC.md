# 数学题库 B 输出中心重构设计说明

版本：2026-06-19  
状态：已按本文档第一版实施  
参考沙盘：`docs/question-bank-teacher-output-sandbox.html`

## 1. 设计目标

输出中心从“题篮导出工具”升级为“教师本卷编辑工作台”。

核心目标：

- 保持当前 HTML 沙盘的版式结构，正式实现时尽量还原。
- 支持小测卷、正式试卷、专题讲义、作业、答案编辑。
- 支持学生版、教师版、答案版三种导出模式。
- 支持题篮、试卷库、历史组卷、AI 讲义整理、显示导出设置。
- 支持全局答题区设置，也支持每道题单独设置答题区。
- 本卷编辑只影响当前输出草稿，不自动回写正式题库。

## 2. 页面总体布局

整体保持沙盘的四区布局：

```text
顶部输出类型与导出模式
左侧本卷结构目录 | 中间 A4 本卷编辑区 | 右侧资源与设置面板 | 最右侧全局抽屉入口
```

### 顶部

左侧显示模块名称：`数学题库 B 教师输出沙盘`。

中部是输出类型：

- 小测卷
- 正式试卷
- 专题讲义
- 作业
- 答案编辑

右侧是导出模式：

- 学生版：不显示答案解析
- 教师版：题目下方显示答案解析
- 答案版：只保留标题、题号、答案解析

右侧操作：

- 打印/PDF
- 导出 Word

说明类文字不放顶部，统一放入最右侧“说明”抽屉。

### 左侧本卷结构

左侧只放真实文档结构，不放使用说明。

示例结构：

```text
标题区
一、知识梳理
  方法提示
二、例题与训练
  1 面积比较图形题
  2 多边形面积计算
  3 平行线间面积
答案解析
```

支持：

- 点击定位到中间本卷编辑区
- 章节折叠/展开
- 后续实现拖拽排序
- 后续实现新增栏目

### 中间本卷编辑区

中间是 A4 预览编辑区，是输出中心的核心。

必须支持：

- 直接编辑标题
- 直接编辑抬头
- 直接编辑栏目名
- 直接编辑题干
- 直接编辑讲义说明
- 临时编辑答案解析
- 插入标题
- 插入说明
- 插入表格
- 插入图片
- 插入分页
- 设置整题下页

本卷编辑区的修改只写入当前 `paperDraft`，不自动改正式题库题目。

### 右侧资源与设置面板

右侧标签：

- 试题
- 试卷
- 历史
- AI
- 设置

右侧只放操作与设置，不放题篮。

### 最右侧全局抽屉入口

最右侧保持窄条：

- 题篮
- 说明

题篮抽屉用于跨模块收集题目。  
说明抽屉用于放规则解释、导出说明、草稿说明。

## 3. 右侧标签功能

### 3.1 试题

用途：从正式题库、试卷题目、待确认题池、AI 相似题中找题。

默认状态：

- 只显示关键词输入、搜索按钮、展开筛选按钮、AI 扩展关键词按钮。
- 筛选项默认折叠，减少占用空间。

展开筛选后显示：

- 范围：正式题库 / 试卷题目 / 待确认 / AI 相似
- 学年：从题库数据动态生成
- 年级：从题库数据动态生成
- 题型：从题库数据动态生成
- 难度：从题库数据动态生成
- 用途：例题 / 变式 / 练习
- 更多：含图 / 含公式 / 本月热题

排序：

- 综合排序
- 使用次数
- 难度
- 时间

题目卡片操作：

- 加入题篮
- 预览
- 加入本卷

### 3.2 试卷

用途：从试卷库中找到整套试卷，并加入当前本卷草稿。

默认状态：

- 显示关键词、搜索试卷、展开筛选、清空筛选。
- 筛选条件默认折叠。

展开筛选后显示：

- 学年：从试卷库数据动态生成
- 地区：从试卷库数据动态生成
- 类型：真题 / 模拟 / 专题卷等，从数据动态生成
- 更多：已入库 / 可整卷加入

试卷卡片：

- 标题字号比题目卡更小，避免占用空间。
- 不常驻展开“原卷题目”列表。
- 操作：查看题目 / 整卷加入 / 删除记录

说明：

- `整卷加入` 表示把整套试卷按原题号加入当前本卷草稿。
- 如果老师只是要打印原卷，应在试卷库模块处理，不在输出编辑区做“整卷打印”。

### 3.3 历史

用途：管理老师之前生成过的本卷草稿。

默认状态：

- 不筛选时按最近编辑时间倒序展示。
- 第一条应是最近编辑的草稿。

筛选：

- 关键词
- 日期：最近 / 本周 / 本月 / 更早
- 年级：从历史记录数据动态生成
- 类别：小测卷 / 正式试卷 / 专题讲义 / 作业
- 排序：最近编辑 / 名称 / 题量

历史卡片操作：

- 打开继续编辑
- 复制为新讲义/新本卷
- 删除记录
- 导出

### 3.4 AI

AI 只做建议或草稿，老师确认后才进入本卷。

核心能力：

1. 题篮生成讲义大纲
   - 先分析题篮
   - 输出知识梳理、例题、变式、练习结构
   - 每个结构块显示对应题号
   - 老师可以逐块加入本卷
   - 也可以一键加入本卷

2. 检查本卷质量
   - 难度递进
   - 题型比例
   - 图片断页
   - 答案解析缺失
   - 来源/标签显示状态

3. 生成教学补充
   - 易错提醒
   - 板书提示
   - 同类变式
   - 课后练习

### 3.5 设置

设置页只管显示、分页、导出和答题区，不放参考图。

显示设置：

- 分值
- 来源
- 知识点
- 难度
- 答题区

分页与导出：

- 纸张：A4 / A3
- 字号：10.5 / 11 / 12
- 一道题不跨页
- Word 按分页预览输出
- PDF 按同一分页生成

PDF 说明：

- PDF 使用当前预览分页、图片、公式渲染结果，适合最终打印。
- Word 保留可编辑结构，但复杂公式和图片需要用兼容格式导出。

## 4. 答题区设计

答题区必须同时支持全局设置和单题设置。

### 4.1 全局答题区设置

位置：右侧 `设置 -> 答题区设置`。

全局模式：

- 按题型自动
- 统一行数

题型默认规则：

- 选择题：默认不显示答题区
- 填空题：默认显示横线
- 解答题：默认显示 6 行
- 几何/证明题：可默认 8 行或更大

全局字段：

- 填空题：横线 / 空白
- 解答题：4 行 / 6 行 / 8 行 / 自定义
- 是否允许单题覆盖

### 4.2 单题答题区设置

位置：每道题下方。

当全局开启答题区后，每道题可以出现一个轻量答题区控制条。

示例：

```text
答题区：按全局 6 行  [改为 4 行] [改为 8 行] [空白] [横线] [拖动高度]
```

单题可设置：

- 跟随全局
- 不显示
- 横线
- 空白
- 方格
- 自定义行数
- 自定义高度
- 整题下页

### 4.3 单题优先级

答题区最终显示规则：

```text
单题设置 > 本卷全局设置 > 输出类型默认设置
```

例如：

- 全局设置解答题 6 行
- 第 3 题单独设置 10 行
- 最终第 3 题显示 10 行，其它解答题显示 6 行

### 4.4 数据结构建议

本卷草稿 `paperDraft`：

```js
{
  answerAreaDefaults: {
    enabled: true,
    mode: "byType",
    fillBlankStyle: "underline",
    solutionRows: 6,
    allowPerQuestionOverride: true
  }
}
```

本卷题目 `paperItem`：

```js
{
  id: "paper-item-1",
  questionId: "question-xxx",
  localEdits: {},
  answerArea: {
    override: false,
    enabled: true,
    style: "inherit",
    rows: null,
    heightPx: null,
    forceNextPage: false
  }
}
```

正式题库 `questionItem` 不保存本次答题区设置，避免污染正式题。

## 5. 数据边界

### 正式题库

正式题库保存题目长期数据：

- 题干
- 选项
- 答案
- 解析
- 图片
- 来源
- 年级
- 章节
- 知识点
- 难度

### 本卷草稿

本卷草稿保存本次输出数据：

- 标题
- 输出类型
- 导出模式
- 题目顺序
- 章节结构
- 讲义说明
- 临时题干修改
- 临时答案解析修改
- 分页设置
- 答题区设置
- 显示设置

### 题篮

题篮保存临时选题：

- 题目 ID
- 默认顺序

题篮不保存本卷排版结构。

### 历史组卷

历史组卷保存已经创建过的 `paperDraft`。

默认排序：

```text
updatedAt desc
```

## 6. 导出逻辑

### 学生版

显示：

- 题目
- 图片
- 选项
- 答题区

隐藏：

- 答案
- 解析

### 教师版

显示：

- 题目
- 答案
- 解析
- 来源/标签按设置显示

### 答案版

显示：

- 标题
- 题号
- 答案
- 解析

默认不显示：

- 完整题干
- 图片
- 选项
- 答题区

### 答案编辑

答案编辑不是导出模式，而是输出类型里的编辑工作区。

用于：

- 核对当前本卷所有答案解析
- 当题干或选项被临时修改后，同步修改答案解析
- 避免题目改了但答案仍是旧答案

## 7. 避免冲突的规则

### 规则 1：本卷修改不自动回写正式题库

本卷里临时改题、改答案、改解析，只保存到 `paperDraft.localEdits`。

如果未来需要回写正式题库，必须提供明确按钮：

```text
同步回正式题库
```

并需要二次确认。

### 规则 2：题篮不是本卷结构

题篮只负责收集题目。

本卷结构由 `paperDraft.sections` 和 `paperDraft.items` 控制。

### 规则 3：试卷整卷加入按原题号

从试卷库整卷加入时：

- 默认按原试卷题号排序
- 保留原卷题号
- 保留试卷来源

### 规则 4：自由组卷按本卷结构

自由选题进入本卷后：

- 按本卷目录顺序输出
- 支持拖拽调整
- 支持 AI 重新整理结构

### 规则 5：答题区设置不污染正式题

答题区只属于本卷输出，不属于题库题目。

## 8. 实施建议

建议分三步实施，降低风险。

### 第一步：输出中心结构重构

- 按沙盘恢复顶部、左侧、中间、右侧、最右侧布局
- 加入试题、试卷、历史、AI、设置标签
- 加入题篮/说明抽屉
- 不先做复杂导出

### 第二步：本卷草稿数据结构

- 新增或完善 `paperDraft`
- 新增或完善 `paperItems`
- 支持本卷临时编辑
- 支持历史组卷

### 第三步：导出与答题区

- 学生版/教师版/答案版
- Word/PDF/HTML 统一使用本卷草稿
- 全局答题区
- 单题答题区覆盖
- 分页与整题下页

## 9. 验收清单

- 顶部不显示说明文字。
- 说明抽屉能打开/收起。
- 历史组卷默认按最近编辑展示。
- 年级、学年、地区、类别筛选表达为动态数据来源。
- 设置页没有参考图。
- 设置页有全局答题区设置。
- 每道题下方可以单独设置答题区。
- 学生版不显示答案。
- 教师版显示答案解析。
- 答案版只显示题号、答案、解析。
- 答案编辑能修改当前本卷答案解析。
- 试卷整卷加入保留原题号顺序。
- AI 生成讲义大纲后，可以逐块加入本卷。
